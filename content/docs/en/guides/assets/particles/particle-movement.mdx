Particle Movement is both used for single particles as well as for a spawner of multiple particles. There are two options to define movement. 
# Initial Velocity
Initial Velocity describes the vector direction and it's strenght in which the particle moves instantly after it's creation.

| Field   | Description                                                                                      |
| ------- | ------------------------------------------------------------------------------------------------ |
| `Yaw`   | The Yaw rotation of the vector from its origin. A random value between `Min` and `Max` is used   |
| `Pitch` | The Pitch rotation of the vector from its origin. A random value between `Min` and `Max` is used |
| `Speed` | The speed of the particles in blocks per second. A random value between `Min` and `Max` is used  |
### Directions:

SOUTH:
```json 
{"Pitch": 0,"Yaw": 0}
```
NORTH:
```json

```


# Attractors
A list of attractors can define the change of movement more precisely. They stack on top of each other, but can also be defined to work just in a specific radius.

| Field                       | Description                                                                                                                                                                                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Position                    | The Offset of the Attractor originating from the center of the spawn                                                                                                                                                                                               |
| Radial Axis                 | The Axis the radial values are calculated around. It's a little more Complicated so [below](./particle-movement#radial-axis) is a preciser explanation                                                                                                             |
| Trail Position Multiplier   | Percentage the attractor moves with it's spawner. <br />`1` (default): moves fully with the spawner <br />`0`: does not move with the spawner                                                                                                                      |
| Radius                      | the maximal distance a single particle can be away from the attractors position to still be affected. <br />Default Value (=empty): always affected                                                                                                                |
| Radial Acceleration         | Positive value: Acceleration from the axis <br />Negative value: Acceleration to the axis -> gravity behaviour                                                                                                                                                     |
| Radial Tangent Acceleration | acceleration of the rotation around the axis. this is not perfect so the particle might move away from / to the center at high speeds                                                                                                                              |
| Linear Acceleration         | acceleration in this direction <br />x+: <br />x-: <br />y+: up<br />y-: down<br />z+: <br />z-:                                                                                                                                                                   |
| Radial Impulse              | starting value of the movement to (positive value)/from (negative value) the axis or center. if the particle moves towards the axis or center, it will stay where this originates from and not move away unless other values are present, that affect the movement |
| Radial Tangent Impulse      | starting value of the rotation around the axis. this is not perfect so the particle might move away from / to the center at high speeds                                                                                                                            |
| Linear Impulse              | starting value of the movement in the given direction <br />x+: <br />x-: <br />y+: up<br />y-: down<br />z+: <br />z-:                                                                                                                                              |
| Damping Multiplier          | multiplier of the directional accelerations. does not work if only impulses are present                                                                                                                                                                            |
# Additonal Explanations
## Radial Axis
You can think of it as an invisible line in 3d space going through the center of the attractor and a point relative to it. It used for calculating Radial Acceleration/Impulse and Radial Tangent Acceleration/Impulse. If it is not present Radial Acceleration/Impulse instead treat the center of the attractor as the point their movement is calculated against. Radial Tangent Acceleration/Impulse doesn't break, but it does some funky stuff.
