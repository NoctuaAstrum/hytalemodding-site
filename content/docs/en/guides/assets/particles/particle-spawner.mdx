ParticleSpawner are the core of a particle. You will spend your time mostly here while creating particles.
Since there are a lot of fields, let's categorize them like in the asset editor.
### General
Contains fields regarding the creation and deletion of the particle in the world

| Field                    | Definition                                                                                                                                                                                                                                               |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Parent                   | Makes this `ParticleSpawner` inherit the values of another `ParticleSpawner` as default values. Spawn Burst and Wave Delay don't seem to be carried over correctly. `Particle` is more or less it's own nested asset, so you can only inherit the whole. |
| Comment                  | A place for your notes                                                                                                                                                                                                                                   |
| Tags                     | Tags are a way to organise assetes for further use with [java plugins](../../../established-information/server/content-categories/plugin)                                                                                                                                                                           |
| Shape                    | The Emit Offset is either calculated in a Sphere or a Cube. More on Emit Shapes [here](./emission-shapes).                                                                                                                                               |
| Emit Offset              | Defines a Minimum Emit Offset Shape and a Maximum Emit Offset Shape. More on Emit Shapes [here](./emission-shapes).                                                                                                                                      |
| Use Emit Direction       | If Initial Velocity has a Speed Value, the Pitch and Yaw of it get ignored and instead the movement is in a line, from/to the emit centre                                                                                                                |
| Total Particles          | How many particles are spawned in the whole lifespan. Uses a random value between Min and Max. Leave empty, if it shouldn't have a limitation                                                                                                            |
| Life Span                | How long Particles get spawned                                                                                                                                                                                                                           |
| Max Concurrent Particles | how many spawned particles can be present at the same time.  <br />if you don't have spawn burst the value should be Particle Life Span (Max) * Spawn Rate (Max)                                                                                           |
| Particle Life Span       | how long a particle lasts                                                                                                                                                                                                                                |
| Spawn Rate               | how many particles get spawned                                                                                                                                                                                                                           |
| Spawn Burst              | if checked the particles spawn at the same time                                                                                                                                                                                                          |
| Wave Delay               | Is the time between spawn bursts                                                                                                                                                                                                                         |
| Initial Velocity         | defines the motion present at the creation of the particle. <br />more on this is found in [Particle Movement](./particle-movement#initial-velocity)                                                                                                       |

### Motion
Contains fields regarding the influence of outside factors on positionand rotation

| Field                             | Definition                                                                                                                                                                                                      |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Particle Rotation Influence       | How the rotation of the particles should be influenced                                                                                                                                                          |
| Particle Rotate With Spawner      |                                                                                                                                                                                                                 |
| Trail Spawner Position Multiplier | -`0`: Particles move with how much it's anchor moves  <br />-`0.5`: Particles rotate their position half the roration its anchor rotates <br />-`1`: Particles don't rotate their position                          |
| Trail Spawner Rotation Multiplier | -`0`: Particles rotate their position around the same axis its anchor rotates  <br />-`0.5`: Particles rotate their position half the roration its anchor rotates <br />-`1`: Particles don't rotate their position |
| Velocity Stretch Multiplier       | how strong particles get additionally stretched in their direction of motion                                                                                                                                    |

### Particle
Is the thing that gets Spawned in, fields are group in 3 categories
#### Material
Contains fields regarding the texture of the particle

| Field                      | Description                                                                            |
| -------------------------- | -------------------------------------------------------------------------------------- |
| Texture                    | is the texture that gets displayed                                                     |
| Frame Size                 | cuts the give texture into frames of this size                                         |
| Soft Particles             | smoothes out a hard edge, if near a block                                              |
| Soft Particles Fade Factor | how strong the edges should get smoothed                                               |
| Use Sprite Blending        | if you have multiple frames and transition between them, the texture gets interpolated |

#### Animation
Contains a list of animation frames (not the same as the frames the texture gets cut to), as well as the one in case of collision. Each frame needs a key (0-100), which renders that frame at the percentage of the particle life span. A frame with the key 50 would be rendered at half the particle lifespan. 

Values between frames are interpolated.

| Field       | Description                                                  |
| ----------- | ------------------------------------------------------------ |
| Frame Index | the number of the texture frame, starting at 0 from top left |
| Scale       | stretches the base size                                      |
| Rotation    | rotates the particle starting at it's base rotation          |
| Colour      | tints the particle to this colour                            |
| Opacity     | the percentage of visibility between 0 and the base opacity  |

`Collision Animation Frame` is the frame that gets displayed, when collision is triggered and `Last Frame`is selected as `Action`. The values act on their own, meaning they are not depenent from the prior `Animation` `Frame`or the default values defined `Initial Frame`.

#### Initial Frame
Contains the values that the animation treats as default values.

| Field                   | Description                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------- |
| UV Option               | how the texture frame should get rotated:  <br /> -  <br /> -  <br /> -  <br /> -  <br /> -  <br /> -  <br /> - |
| Scale Ratio Constraint  | how the with and height of the particle are linked <br /> - `None` <br /> -  <br /> -  <br /> -           |
| Initial Animation frame | defines the base values and starting frame                                                        |
| -> Frame Index          | the texture frame that should get displayed upon spawn                                            |
| -> Scale                | this scale is treated as `1` in `Animation`                                                       |
| -> Rotation             | this rotation is treated as `0` in `Animation`                                                    |
| -> Colour               | this is the starting colour                                                                       |
| -> Opacity              | this opacity is treated as `1`                                                                    |
