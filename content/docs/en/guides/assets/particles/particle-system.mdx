A `ParticleSystem` is a collection of indiviual `ParticleSpawner`. These can be customized further for their position/movement, active timespan and amount. The following is sturctured like how it would be shown in the asset editor

| Field           | Description                                                                                                                                                        |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Parent          | Inherits the values of he given `ParticleSystem`                                                                                                                   |
| Comment         | A place to note imformation down                                                                                                                                   |
| Tags            | Tags are used for filtering assets within a plugin                                                                                                                 |
| ParticleSpawner | An array cotainung multiple [ParticleSpawnergroup]()                                                                                                               |
| CullDistance    | The max amount a system can be away from the camera to still get rendered                                                                                          |
| BoundingRadius  |                                                                                                                                                                    |
| IsImportant     | If checked, does not unreder the system if it is outside for the camera view. Check this if your partilce suddelny dissappear when you move/rotate the camera away |
| LifeSpan        | How long this Sytem is active before disabeling itself                                                                                                             |
