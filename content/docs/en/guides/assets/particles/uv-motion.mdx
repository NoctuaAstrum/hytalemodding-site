UV Motion controlls how a texture gets distorted. It is mostly used for smoke.

| Field               | Description                                                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Texture             | Select your flow map texture. This controlls in what direction the texture gets distorted.                              |
| Add RandomUV Offset | If true, overlays the flow map texture at a random offset position.                                                     |
| Speed X             | Moves the flow map texture                                                                                              |
| Speed Y             | Moves the flow map texture                                                                                              |
| Strength            | Is a multiplicator for how strong the distortion is applied                                                             |
| Strength Curve Type | Controlls how the strength evolves over time                                                                            |
| Scale               | Scales the flow map texture with the factor 1/scale. The texture gets tiled if it is smaller, than the particle texture |
